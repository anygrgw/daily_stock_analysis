# 投资书单 → 买卖基准与逻辑

本页记录如何把一份经典投资书单，提炼为项目内可被分析引擎自动加载的**策略 skill**（`strategies/*.yaml`），并说明每个策略的买卖基准与逻辑。产出面向后续「猎股」页面（台股潜力罗列）：让清单在现有技术型策略之外，补齐**价值、顺势资金控管、行为纪律**三个差异化视角。

- 策略机制与编写方式见 [`strategies/README.md`](../strategies/README.md)。
- 这些策略默认**不进入默认激活集，也不进入路由 fallback 集**（不设 `default_active` / `default_router`），符合「不配置也可运行，配置后增强能力」；需要时通过技能选择显式启用，不改变默认分析行为。
- 台股（`tw`）自 v3.24.0 起为一等市场，策略以自然语言描述、与市场无关，可直接用于台股潜力筛选。

## 书单分组与策略映射

| 书单分组 | 代表书目 | 提炼视角 | 落地策略 |
| --- | --- | --- | --- |
| 一. 投资理财入门观念 | 富爸爸穷爸爸、致富心态、有钱人想的和你不一样、巴比伦富翁的理财课 | 现金流、复利、风险控制、金钱心理 | `trading_discipline`（资金与风险管理层） |
| 二. 投资基础与观念 | 漫步华尔街、投资金律、约翰柏格投资常识 | 低成本、长期、分散、仓位与成本纪律 | `trading_discipline`（资金管理）+ `value_margin_of_safety`（估值纪律） |
| 三. 价值投资与基本面分析 | 智慧型股票投资人、巴菲特写给股东的信、彼得林区选股战略、护城河投资优势 | 内在价值、安全边际、护城河、公司分类、PEG | `value_margin_of_safety` |
| 四. 交易心理与技术分析 | 交易心理分析、海龟投资法则、股票作手回忆录 | 顺势突破、ATR 仓位、硬止损、加码、交易心理 | `turtle_trend` + `trading_discipline`（心理层） |
| 五. 商业思维与自我成长 | 原子习惯、快思慢想、原则：生活和工作 | 系统化决策、认知偏误、复盘 | `trading_discipline` |

> 说明：入门心态类与指数化投资类不是逐笔选股方向，其可执行部分（现金流、复利、低成本、分散、仓位纪律）汇入 `trading_discipline` 的资金 / 风险管理层与 `value_margin_of_safety` 的估值纪律；成长与质量视角已由既有 `growth_quality`、`emotion_cycle` 等策略覆盖，本次不重复实现。

## 三个差异化策略

### 1. `value_margin_of_safety` 价值与安全边际
- **来源**：智慧型股票投资人（葛拉汉）、巴菲特写给股东的信、护城河投资优势（晨星）、彼得林区选股战略。
- **买入基准**：现价 ≤ 内在价值 ×(1 − 安全边际)，折价 ≥ 25%~30%；具备宽 / 窄护城河；PEG < 1 或 PE/PB 低于自身历史与同业；财务稳健；利空为暂时性。
- **卖出 / 回避**：安全边际消失（现价 ≥ 内在价值）；护城河被侵蚀；价值逻辑证伪；财务恶化；价值陷阱。
- **猎股维度**：价值潜力（标注估算内在价值区间与折价幅度）。

### 2. `turtle_trend` 海龟顺势与资金控管
- **来源**：海龟投资法则、股票作手回忆录（李佛摩）。
- **买入基准**：突破唐奇安上轨（20 / 55 日高）+ 多头排列 + 量能配合；仓位按 N（ATR）计算；明确 2N 硬止损；顺李佛摩关键点方向。
- **卖出基准**：跌破离场通道（10 / 20 日低）、触及 2N 止损、趋势转空。
- **纪律禁令**：不追高乖离、不摊平亏损、不情绪性平掉盈利单。
- **猎股维度**：趋势动能潜力（标注突破点、N 值、建议止损位）。

### 3. `trading_discipline` 交易纪律与行为护栏
- **来源**：交易心理分析（道格拉斯）、快思慢想（康纳曼）、原则（达利欧）、致富心态、富爸爸穷爸爸、巴比伦富翁、有钱人想的和你不一样。
- **定位**：元策略 / 过滤层，不单独给方向，对其他策略候选做行为纪律与资金风险审查。
- **一票否决 / 降权**：乖离 > 5% 追高、扛亏移动止损、仓位过重无止损、利空未消化情绪追入、纯情绪 / 羊群驱动。
- **猎股维度**：纪律过滤层，对情绪过热、财务或仓位风险标的降权 / 加警示，提升清单质量。

## 与既有核心交易理念的关系

三个策略均复用 `strategies/README.md` 的核心交易理念编号（`core_rules`）：

- `value_margin_of_safety` → `[1, 5]`（严进 / 安全边际、风险排查）
- `turtle_trend` → `[2, 3, 6]`（趋势、效率量能、量价配合）
- `trading_discipline` → `[1, 5]`（严进不追高、风险排查一票否决）

后续台股潜力罗列页面可按维度组合本组策略输出：
